# Published 1941 Army message n-gram counts

`BigramFrequency1941.txt` and `TrigramFrequency1941.txt` were extracted
from CryptoCellar's [1941freq.zip](https://cryptocellar.org/bgac/1941freq.zip),
linked from [Five Easy Pieces](https://cryptocellar.org/bgac/key-of-e.html).
The source says these counts were compiled from raw German Army message decrypts.
Only the line endings were normalized from CRLF to LF; the n-grams and counts
were left unchanged.
