0Start here

Enigma was the German forces' cipher machine in the Second World War: a typewriter-sized box with a keyboard and 26 lamps. Press a key and a different letter lights up. The operator copied the lit letters down and sent them by radio. Anyone listening heard only gibberish, but a receiver with a machine set up the same way could type the gibberish in and read the original message off the lamps.

How the machine scrambles

Each key sends electric current through a maze of wires: across a plugboard, through three wheels, into a reflector that turns it round, and back by a different route to a lamp. Before the current flows, the right-hand wheel turns one step, so the maze is different for every letter. Type A five times and a different lamp can light each time.

The reflector has two side effects. Typing the scrambled text back in, from the same start, gives the original. And a letter can never come out as itself, a weakness the codebreakers used.

The settings on the key sheet

Wheel order
Which three of the five wheels go in, and in what order. Each wheel is wired differently.
Ring setting
Turns each wheel's wiring against the letters printed on its rim, so the letter showing in the window doesn't give away where the wiring sits.
Plugboard
Short cables that swap pairs of letters on the way in and again on the way out. With ten cables, 20 of the 26 letters are swapped.
Message key
The three letters the wheels start at for this message. The operator picks a new one for every message.
Grundstellung
A second start the operator picks, used only to scramble the message key itself. It goes out unscrambled at the head of the message so the receiver can unlock the key.

The first three came from a printed sheet issued to every operator on a network and changed each day. The last two the operator chose himself.

What to do on this page

  1. Key sheet. Keep the demo settings or type your own, then press Set the machine. The box under the form shows exactly what would go out over the radio.
  2. The machine. Press Press next key to send one letter through, or Play to run the whole message. Orange is current going in, blue is current coming back. Switch to Decipher to watch the same settings turn the gibberish back into German. You can also type on your own keyboard.
  3. Sweep. Now you are the codebreaker, with nothing but the gibberish. The page tries all 17,576 starting positions of the wheels, ignoring the plugboard, and scores how much each result's letter counts look like a real language. Slide Plugs the sender used down to see how the plugboard hides the answer.
  4. Climb. From one wheel position, the page guesses the plugboard one cable at a time, keeping each change that makes the text read more like German. Press Run the climb and watch the green letters spread.
  5. Verdict. Compares what the attack found with the sender's real settings, and with what this repository measured over many trials.

Look for the blue In plain words notes in each section for more explanation. Everything, the attack included, runs inside your browser.

In plain words: how the receiver learns the message key

Both ends already hold the day's key sheet, but the message key changes with every message, so the receiver has to be told it. Sending it openly would hand it to the enemy. Instead the operator sets the wheels to a Grundstellung of his own choosing, types the message key through the machine, and sends the Grundstellung openly followed by the three letters that lit. The receiver sets his wheels to that Grundstellung, types the three letters, and reads the message key off his lamps. Then both set the wheels to the message key for the message itself.

In plain words: how to read the diagram
  • The diagram is laid out the way the current flows, not the way the box looks. The left column is the 26 keys and lamps, A at the top. Current enters the plugboard, then the right wheel, middle wheel, left wheel and the reflector (UKW-B), then comes back the same way on a different line.
  • Each grey line is one wire inside a wheel, joining a contact on one side to a contact on the other. When a wheel turns, its whole bundle of wires shifts by one row.
  • The big letter above each wheel is what the operator sees in the window. A window outlined in orange means that wheel just turned. The small letters down each wheel's left edge are its rim letters at each contact.
  • The strip of boxes under the diagram spells out the same path letter by letter: K→P means the current came in as K and left as P.

3Stage 1 · Sweep the wheel starts

The interceptor has only the ciphertext. The plugboard multiplies the keyspace beyond any search, so the method this repository follows (Weierud and Sullivan, with Ostwald and Weierud's two-phase scoring) first ignores it: decrypt with no plugs at every wheel setting and keep the settings whose output has the highest index of coincidence, the chance that two letters drawn from it match. German plaintext scores about 0.07 and random letters 0.0385.

The rings and starts multiplied overcount by 26: no wheel sits to the left of the left wheel to use its notch, so only the difference between the left wheel's ring and its start changes the output. The start is the message key, chosen for each message; the key sheet fixes the wheel order, rings and plugboard for the day.

This page sweeps all 17,576 starts of the sender's wheel order with the sender's rings held, one sixtieth of the {{ranked_population}} settings a Phase 1 sweep ranks per indicator ordering.

In plain words: what the sweep is measuring

Every language uses some letters much more than others: German is full of E, N, R and the Army's X for a full stop. Gibberish uses all 26 letters about equally. The index of coincidence measures that lopsidedness: pick two letters from the text at random, and it is the chance they are the same letter. Real German scores about 0.07; evenly spread gibberish about 0.0385.

At a wrong wheel start the decryption is gibberish. At the right start the wheels are right but the cables are missing, and the current passes the plugboard twice, once on the way in and once on the way out. A letter still comes out correct when neither the ciphertext letter nor the plaintext letter has a cable. Those survivors make the text a little lumpier than chance, so it scores a little higher. That is all the sweep looks for.

  • Each grey bar counts how many of the 17,576 starts scored in that range. The tall hump is the wrong starts.
  • The orange line marks the sender's real start, which the codebreaker would not know. The blue dashed lines mark pure gibberish and the real message's own score.
  • With few plugs, the orange line sits far to the right on its own. With ten plugs, it sinks into the hump: most letters get swapped on the way in or out, and the lumpiness is washed away.

4Stage 2 · Climb the plugboard

At one wheel setting the climb tries every change of one plug: all 325 letter pairs and every unplug. It keeps the single best change and repeats until nothing improves. It climbs on index of coincidence first, then on the log-likelihood of the text under the published 1941 Army bigram and trigram counts, at most {{max_pairs}} pairs and {{max_passes}} passes per phase, as {{calibration_id}} configures it.

In plain words: how the climb guesses the cables

Think of tuning an old radio: nudge the dial, and keep the nudge if the sound gets clearer. Here a nudge is one cable change. On each pass the page tries every possible single change, joining any two letters with a cable (unplugging whatever they were joined to) or pulling one cable out, decrypts the whole message each time, and keeps the one change that helps most. It stops when no single change helps any more.

It judges "clearer" in two ways, one after the other. First by the same letter-count lumpiness the sweep used, which gets the climb started. Then by how often the text's two- and three-letter runs, such as EIN or UNG, turn up in real 1941 German Army messages. That second score is much sharper at telling German from near-German.

  • Each step along the charts is one pass. The shaded part is the second scoring phase.
  • The climb can stall on a wrong answer that no single change improves, like a hiker stuck on a lower peak in fog. Climbing from the sweep's top start when it isn't the sender's shows what that looks like.

    In plain words: what these numbers mean

    This page cheats in one way: it sweeps only the sender's own wheel order and ring setting. A real attacker would have to repeat the sweep for every wheel order and ring setting and then climb from hundreds of candidates. The figures below test each stage on its own, then the whole search. The first is how often the sweep would keep the true setting among its top candidates. The second is how often the climb recovers the plugboard when it is handed the true wheel settings, as The sender's start option on this page is. The third is the complete search, run on real messages from 1941 that no one has yet broken.
